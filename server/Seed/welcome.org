* Introdução
Este ficheiro é um ficheiro *org-mode* normal, guardado no servidor. Podes abri-lo
também no Emacs. Suporta /itálico/, _sublinhado_, =verbatim=, ~código~ e +riscado+.

Links: [[https://orgmode.org][site do Org]], [[*Tarefas][ir para Tarefas]] e notas de rodapé[fn:1].

- Clica no ▸ para dobrar/desdobrar secções
- Clica no estado (TODO/DONE) para o alternar
- Faz duplo-clique no título para o editar
- Carrega em =Enter= numa secção selecionada para editar o texto
